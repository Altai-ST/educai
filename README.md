# «За минуту» — образовательный портал (1–11 класс, все предметы)

Портал с видеоуроками и интерактивными заданиями. У портала своё нейтральное оформление:
шрифты Unbounded и Onest, тёмные и светлые секции, у каждого предмета свой цвет. Видео появляется
только на странице темы. Тема состоит из **этапов**, и у каждого этапа есть видео, пауза-вопрос, конспект и задания.
Задания этапа нарисованы в стиле его видео: внутри этапа действует палитра и шрифт ролика.

## Запуск
```bash
npm install
npm run media      # копирует видео, постеры, превью, спрайты кадров и звуки из ../projects
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/ (на хостинге — fallback всех путей на index.html)
```

## Деплой (MVP)
Сайт опубликован на GitHub Pages: **https://altai-st.github.io/educai/**. Исходники лежат в ветке `main`,
готовая сборка — в ветке `gh-pages`.
Обновить сайт: `npm run deploy`. Скрипт собирает сайт с базой `/educai/`, создаёт копию страницы для каждого
маршрута и отправляет сборку в `gh-pages`; GitHub публикует её примерно за минуту.

## Страницы
- `/` — главная: поле частиц с формулами разных предметов (реагирует на курсор), поиск, выбор
  класса, сетка предметов, «как устроена тема», новые темы, классы 1–11, возможности.
- `/predmety`, `/predmet/:id` — предметы и темы предмета по классам.
- `/katalog?predmet=&klass=&status=&q=` — каталог с фильтрами и поиском.
- `/tema/:id/:stage?` — тема: карта этапов с прогрессом, видео этапа (главы, превью кадров,
  субтитры по словам, пауза-вопрос, текст ролика), конспект, задания, переход к следующему этапу.
  У этапа без видео вместо него план и кнопка «Хочу эту тему».
- `/progress` — XP, уровни, серия дней, мои темы по этапам, награды.
- Ctrl/⌘ K — поиск по предметам, темам, главам и фразам из видео (открывает нужную секунду).

## Где что лежит
```
src/data/catalog.ts   предметы, темы, этапы (BRAND — название портала)
src/data/videos.ts    видео этапов: главы, пауза-вопрос, конспект (тайминги — src/data/tl/*.json)
src/tasks/<видео>/    задания этапа + index.ts; подключение — src/tasks/registry.ts
src/tasks/engine.tsx  движок заданий, src/tasks/kit.tsx — кирпичики (docs/TASKS.md)
src/player/           плеер и текст ролика
src/pages/            страницы; /lab/<видео>/<задание> — стенд для одного задания
```

## Как добавить тему
1. Добавить тему в `TOPICS` (`src/data/catalog.ts`): предмет, класс, раздел и список этапов.
   Этапы без `video` показываются как «скоро».
2. Когда видео этапа готово, положить его в `../projects/<slug>/out/`, добавить slug в
   `scripts/media.sh` и выполнить `npm run media`.
3. Описать видео в `VIDEOS` (`src/data/videos.ts`) и прописать `video: '<slug>'` у этапа.
4. Сделать задания в `src/tasks/<slug>/` по `docs/TASKS.md` и подключить их в `registry.ts`.

Сейчас с видео работает одна демо-тема: «Дроби, десятичные и проценты» (математика, 5 класс,
3 этапа, 18 заданий). Остальные темы каталога — заготовки со статусом «скоро».
